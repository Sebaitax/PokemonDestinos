# Créditos

## Base técnica

Este proyecto se construye sobre [pokefirered](https://github.com/pret/pokefirered), la descompilación de Pokémon FireRed/LeafGreen mantenida por **pret** y su comunidad de contribuidores.

## Traducción al español

Los textos en español de este proyecto parten de [pokefireredlatino](https://github.com/SomeRandomSponge/pokefireredlatino), traducción al español latino de pokefirered. Por los términos de esa traducción, se acreditan explícitamente:

- **SomeRandomSponge** — autoría del proyecto de traducción.
- **Juanjo/J2M2** — sistema de semántica de género (`gender_semantics_esp`), adaptado a pokefirered por SomeRandomSponge.
- **Z-nogyroP** — nombres de movimiento de 16 caracteres (basado en CFRU), adaptado a pokefirered por SomeRandomSponge.
- **kakarotto** (WaH) — tutorial "Traduciendo textos", usado como referencia para los mensajes de batalla.
- **Kantopia** — traducción de japonés a inglés de textos censurados usada como referencia.
- **InmortalKaktus** — herramienta de configuración de la descompilación.
- **Cefer** — correcciones al archivo de créditos y README originales.
- **Lunos** — método para pronombres con género en batallas.

Nuestro texto en español fue portado y adaptado (incluyendo abreviaciones de nombres de objetos para respetar el límite de 13 caracteres del motor) a partir de esa traducción, no copiado 1:1 completo del repositorio.
