# Pokémon Destinos

> En una región donde el linaje y el dinero dictan el valor de una persona, el viaje Pokémon clásico es un lujo reservado para las élites.

Pokémon Destinos es una historia de supervivencia, rebelión y lucha de clases, donde el protagonista no busca simplemente ganar medallas, sino sobrevivir en un mundo diseñado para aplastarlo.

## Sobre el proyecto

Un ROM hack construido sobre la base de **Pokémon FireRed**, con sistemas propios de:

- **Karma y Respeto** — dos medidores persistentes que reaccionan a tus decisiones y ramifican la historia.
- **Robo de objetos** — mecánicas de sigilo para sobrevivir cuando el sistema no te deja otra opción.
- **Robo de Pokémon** — la lucha de clases también se juega en el equipo rival.

## Estado

En desarrollo activo. El trabajo del día a día vive en la rama [`development`](../../tree/development), donde se encuentra el plan completo (`PLAN.md`).
